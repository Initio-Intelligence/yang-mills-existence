## 3. A3: Lemma S′, (TW), (TW-osc), Theorem R″, (Traj-w)

### 3.1 Lemma Traj: (Traj-w) is a consequence of the upper slope

**Lemma Traj.** Let Y_j := g_j^{−2} ≥ Y_* > e, ℓ_j := log Y_j, and assume the upper slope
 Y_b ≤ Y_k + β′(k−b) for all b ≤ k.
Let R_j be the smallest power of L with R_j ≥ ℓ_j^r ([III] (2.5), source). Then for b ≤ k and every q > 0:
 (T1) ℓ_b^q ≤ (1 + β′(k−b)/Y_k)^{q/ℓ_k} ℓ_k^q;
 (T2) R_b ≤ L(1 + β′(k−b)/Y_k)^{r/ℓ_k} R_k; in particular R_k ≤ 2LR_{k+1} and D_k = 8LR_{k+1} ≥ 4R_k once (1+β′/Y_*)^{r/ℓ_*} ≤ 2;
 (T3) for every polylogarithm P_j = Aℓ_j^p: R_bP_b² ≤ LA²(1+β′(k−b))^{(r+2p)/ℓ_*} R_k^{1+2p/r}, which is (Traj-w) with p_R = max(1+2p/r, (r+2p)/ℓ_*).

*Proof.* With x := β′(k−b)/Y_k, ℓ_b ≤ log(Y_k(1+x)) = ℓ_k + log(1+x), and (1 + t/ℓ)^q ≤ e^{qt/ℓ} with t = log(1+x) gives (T1). ℓ_j^r ≤ R_j ≤ Lℓ_j^r (ℓ_j ≥ 1) and (T1) with q = r give (T2). (T3): (T1) with q = r+2p, then ℓ_k^r ≤ R_k and D_k ≥ 4R_k. □

The hypothesis is the first inequality of [III] (2.6) (source input; p.255: "g_n ≤ (1+g_n²β′(n−m))^{1/2}g_m" for n > m), which the source derives from its renormalization group equations and lists among its standing inequalities together with (2.7)–(2.9) (source input, pp.255–256; (2.9) reads "R_m ≤ L(1+g_n²β′(n−m))^{β₀}R_n ≤ (L+1)(n−m)^{β₀}R_n"). So [Native-tag admission, trajectory weights and the obstruction to propagation]'s sentence "(Traj-w) is not implied by LFR II's Theorem 1 hypothesis" is misleading: it is one of the inequalities under which the source's induction runs. On the trajectory the hypothesis is [B03] Lemma 3.4(a) (stated (a) there and verified in [Native domains and the one-step comparison](coupling_native_estimates.md) §3; cited, not assumed here). 

**Consequence.** (Traj-w) needs no new export from B-03/B-05 beyond Lemma 3.4(a). ### 3.2 Re-derivation of the count; Lemma S′ is correct but is not the right lemma

Lemma S′ itself is a one-line statement and is correct deduction. Two remarks.
1. *Sharper form deduction.* Inside the tag the unit is ≤ s_b, so a cell at depth q below the face has d_g ≥ D + q. Hence Σ_{y∈G_b∩Y^∼}e^{−(μ/2)d_g(x_i,y)} ≤ (1−e^{−μ/2})^{−1}·#(face cells)·e^{−(μ/2)D}: the factor (C_TR_b)^d can be replaced by C(μ)(C_TR_b)^{d−1}. This is cosmetic.
2. *Its hypothesis fails where Theorem R″ uses it.* The hypothesis is sup_y Σ_{ρ∋y}w_ρ ≤ s over grade-b grid cubes y with s independent of the tag. For the tag's own terms the source gives (source input; p.377)
 |V(Y,(𝐔,𝐉))| ≤ O(1)Σ_{j=1}^{k}|Γ_j⁰ ∩ Y| if Y is a component of Z^∼, (1.69)
 "Here {Γ_j⁰} denotes the old determining set". That is O(1) of sup weight per old site at **every** old scale j. The old scales n ≤ h of a deep tag occupy a region of Euclidean size ≤ 100MR_nL^{n−b}s_b: all of them sit over O(1) cubes of G_b. So with sup weights, s grows linearly with the hidden depth. Lemma S′ then gives a bound that grows with the hidden carrier distance, which the completion test forbids.
