# The retained sector of the regular Q step

The M-04 statement concerns one regular RG step under an explicit
incoming marked budget. It is not the assertion that an old reset
posterior has a uniform microscopic local moment. The following exact
split is useful for keeping those tasks separate.

## 1. Actual regular conditioning

In the C-01/C-07 common coordinates write the regular input as (z,u,v):
z is the present independent free current integrated in Λ_{k+1}; u
contains surviving older raw and ordinary fluctuation variables; v
contains the other retained data, including the exterior coordinates of
the present current chart. The actual conditional law is

\[
 (QF)(u,v)=\int F(\chi(z,u,v))\,\nu_{u,v}(dz),
 \qquad \nu_{u,v}1=1.                                  \tag{RQ.1}
\]

Every coordinate relocation, coarea factor, old Gaussian response,
E/B/R term and live selector is part of the stated map or measure.
Older variables are parameters; they are not included in the present
exterior Gaussian force merely by concatenating vectors.

For a completed component, LFR II printed p.392, following
(1.103)–(1.104), states that the remaining multiplication factor
T′_k(Y)1 depends only on the new V_k restricted to Y and does not
participate in the next renormalization transformations. The next
ordinary current substitution is outside the buffered old Z_k, by
CMP119 (3.2)–(3.5), so this particular multiplication factor is retained.
The boundary activities produced by integrating the whole earlier
boundary exponential are separate functions and are not declared
independent of z.

## 2. Exact identity on a retained mark tag

Suppose an actual pulled-back incoming tag is

\[
 F_X(\chi(z,u,v))=f_X(u,v)                             \tag{RQ.2}
\]

for every admitted common-coordinate point and on the chosen ambient
extension. Then

\[
 QF_X=f_X.                                             \tag{RQ.3}
\]

The independent insertion/kernel copy is simply

\[
 H_X(y_{\rm ins},y_{\rm ker})
 =\int f_X(y_{\rm ins})\,\nu_{y_{\rm ker}}(dz)
 =f_X(y_{\rm ins}).                                   \tag{RQ.4}
\]

Its new normalized-kernel current is identically zero. The incoming
direct and old-current records are preserved under the actual retained
coordinate pullback. This is an identity of normalized probability
kernels, valid also for discrete differences; it does not require a
small kernel score.

For the quantitative M-03 statement, use the actual retained native
regulator of this tag. If its retained coordinates, scale labels and
physical footprints are carried to the output unchanged, that
regulator is bounded by the output regulator on the coarsened carrier.
The moment law on these coordinates is their exact common marginal.
With the corresponding coarsened supported carrier, the only units
change in the source-order-one norm is h′⁴/h⁴=L⁴. If the actual
coordinate assignment enlarges the footprint, its geometric factor
must additionally be charged; it is not set equal to one by notation.

A generic input estimate which uses energy of eliminated coordinates
does not establish this retained-regulator hypothesis. Annex Y
(M.28)–(M.28c) still requires the true regulator and coordinate-path
costs. Likewise a tag which is only approximately z-independent is
not covered by (RQ.3).

## 3. Exact cancellation of a retained-only density factor

If the actual unnormalized current density factors as

\[
 h(u,v)\,r(z;u,v),\qquad h(u,v)>0,
\]

then on every active fiber

\[
 \nu_{u,v}(dz)
 =\frac{r(z;u,v)\,dz}{\int r(s;u,v)\,ds}.             \tag{RQ.5}
\]

All derivatives or finite differences of h cancel from this same
normalized ratio. For an ambient estimate one can explicitly choose
the cancelled-ratio extension wherever its denominator has a positive
continuation. The default inactive reference-point extension need not
have this regularity, and is not silently identified with that
continuation.

The equality does not remove h from the marginal law of (u,v), or
from a comparison between distinct histories. It only identifies the
regular conditional kernel at fixed retained data.

## 4. The genuine remaining responses

Three different objects must be distinguished:

| Object | Status in the regular Q step |
|---|---|
| An incoming mark tag satisfying (RQ.2) | Preserved exactly; its new kernel current is zero. |
| A retained-only source multiplication factor, including the literal completed T′_k(Y)1 factor | Cancels from the fixed-fiber normalization, with the ambient-extension qualification above. |
| A surviving ordinary Gaussian precision ratio or completed boundary activity evaluated on Φ(z) | Remains in the actual current density and can create new dependence of an integrated mark. |

For the last row, a representative ordinary response is

\[
 -\frac12 a_j^{\mathsf T}
 [S_j(\Phi(z))-S_j(\Phi(0))]a_j,                       \tag{RQ.6}
\]

where the derivative of the principal inverse inside the Schur form
is retained. Its old endpoints lie in the actual updated old domain;
the source annular estimate and age sum in
[M04 Surviving Old Slot Geometry](M04_Surviving_Old_Slot_Geometry.md) apply to its genuine localized
coefficient paths. The old cutoff supplies its pointwise P_j² factor.
No old reset posterior is used for that ordinary response.

A completed normalized component has a different boundary response.
LFR II (1.103) integrates the whole boundary exponential before the
new regular step. The source deliberately omits internal tree costs
for its fixed component domains. A subsequent absolute M-03
carrier/current estimate must either recover actual supported
primitive dependence or prove a stronger localized component theorem.
Its source-free mass, already cancelled in the normalized operation,
is not an available second rarity factor.

Thus retaining old payloads removes an unnecessary reset-moment task
from this part of M-04, but does not by itself close the actual
boundary-response carrier sum. In particular, a new kernel dependence
on an old component which was absent from the incoming mark cannot be
charged solely to that mark's incoming carrier budget.
